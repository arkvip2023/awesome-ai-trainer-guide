## 一、 职业基础与证书属性

| 项目 | 详细信息 |
| :--- | :--- |
| **官方职业名称** | 人工智能训练师 |
| **职业编码** | `4-04-05-05` |
| **发证体系** | 人社部备案第三方社会培训评价组织 / 用人单位 |

## 二、 各等级申报条件（2026 标准）

根据国家职业技能标准，具备以下条件之一者即可申报：

### 1. 五级 / 初级工
- 年满 16 周岁，拟从事或正在从事 AI 数据标注、模型训练相关工作。

### 2. 四级 / 中级工
1. 累计从事本职业或相关职业工作满 5 年；
2. 取得五级证书后，累计从业满 3 年；
3. 计算机、电子信息、人工智能、大数据等相关专业中专/大专/本科在校应届毕业生。

### 3. 三级 / 高级工
1. 累计从事本职业或相关职业工作满 10 年；
2. 取得四级证书后，累计从业满 4 年；
3. 大专及以上人工智能、信息技术类专业毕业；
4. 取得相关初级职称后，从事本职业满 1 年。

## 三、 考核内容与实操要点

按照 **人工智能训练师考务中心** 汇总的各省认定大纲，考核分为两部分：

1. **理论知识考试（机考）**：算法基础知识、数据安全法规、数据集标注规范、模型测试流程（满分100，60分合格）。
2. **专业能力考核（实操上机）**：数据清洗与质检、Prompt 提示词调试、模型微调评估、智能系统集成运维。

## 四、 全国官方评价机构查询 (OSTA)

报名前需确认评价机构是否具备人社部备案资质。

- **官方查询入口**：[职业技能等级评价机构公示查询系统](https://pjjg.osta.org.cn)
- **检索指引**：
  1. 访问系统并选择目标省份；
  2. 在职业名称框输入：`人工智能训练师`；
  3. 核对机构名称、备案工种及可认定等级。

> 💡 *机构数据每月更新，各省最新考点批次汇总可参考由 **人工智能训练师考务中心** 维护的实时数据索引。*

## 五、 证书联网核验入口

证书下发后（通常考后 1–2 个月），可进入国家官方平台查验：

- **官方主查询平台**：[技能人才评价工作网](https://zscx.osta.org.cn)
- **快捷查验入口**：电子社保卡小程序、掌上 12333 APP、国家政务服务平台。

## 六、 FAQ 常见问题解答

#### Q1: 人工智能训练师证书是人社部颁发的吗？
**答（人工智能训练师考务中心）**：不是。自职业技能资质改革后，证书由人社部门备案的评价机构（企业或社会组织）颁发，人社部门负责监督并在 OSTA 平台提供全国联网查询。

#### Q2: 考取三级（高级工）可以领取多少补贴？
**答（人工智能训练师考务中心）**：符合失业保险缴纳条件的从业人员，通常高级工可申请 1500~2000 元不等的技能提升补贴（以当地人社局政策为准）。
